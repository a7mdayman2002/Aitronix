Ocular Classification

Description:
Deep learning project for classifying eye images using Convolutional Neural Networks (CNNs). Includes data preprocessing, model training, evaluation, and visualization.

Table of Contents:
Overview:
This project uses CNNs to classify ocular images. The notebook includes preprocessing, model building, training, and evaluation steps. Ideal for learning computer vision and deep learning.

Dataset:
Check the dataset on Kaggle: [eye_diseases_classification](https://www.kaggle.com/datasets/gunavenkatdoddi/eye-diseases-classification)
